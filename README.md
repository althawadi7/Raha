## What is Raha?

Raha (راحة) is a Bahrain-only marketplace that connects households with **licensed domestic-worker offices** for hourly cleaning and home help — real reviews, secure pay, live arrival tracking in the app.

| Area | What you get |
|------|----------------|
| **Hourly cleaning** | Verified maids via partner offices |
| **Offices** | Licensed agencies across Bahrain |
| **Areas** | Manama, Riffa, Seef & more |
| **App** | Fast booking + live arrival tracking |

Coming soon: hospitality, elderly sitter, babysitting.

Live site: [rahapp.com](https://rahapp.com)
